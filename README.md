# TO-DOwithTs

This app help you to set(organize) your to do list which mean you can write down what have to achive by when and if you done (complete) the task you can select it to complete section and set remainder too if the date of completion running out, also you can edit, delete too.

to add new task click the plus round button at the bottom right of the screen then fill the input for task discription and alarm if needed

to set task to completed click the check box and to edit click the list discription (name)
